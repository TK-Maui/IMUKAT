# IMUKAT（テストプレイ版）

探偵1人と怪盗集団が、互いの位置を隠したまま建物の中で駆け引きするボードゲーム「IMUKAT」のテスト版です。企画書のアプリ版（隠れた情報だけアプリで管理する方式）を試すためのものです。

## 遊び方は3つ

| 遊び方 | 内容 |
| --- | --- |
| 部屋を作る | 全員がそれぞれのスマホやPCで参加して遊ぶ |
| 部屋に参加する | 部屋番号（5文字）か招待リンクで参加する |
| 1人でテストする（1台モード） | 通信なしで、1つの画面で全員を切り替えながら操作する |

## オンラインの始め方

1. 1人（部屋を作る人）がページを開き、名前を入れて「部屋を作る」を押します。
2. 表示された部屋番号を伝えるか、リンクをコピーして送ります。
3. ほかの人は名前と部屋番号を入れて「参加する」を押します。
4. 部屋を作った人がテストの設定を決めて「始める」を押します。

- ゲームの進行は部屋を作った人の端末で管理しています。遊んでいる間は画面を開いたままにしてください。
- 部屋を作った人が画面を閉じてしまっても、同じ端末で開き直して「前回の部屋を再開」を押せば続きから遊べます。ほかの人は同じ名前・部屋番号で参加し直してください。
- 通信が切れたときは自動でつなぎ直します。直接つながらない回線では、自動で中継サーバー経由に切り替えます。
- 内部エラーが起きた操作は自動で取り消され、ゲームは止まりません。
- スリープなどで進まない人がいるときは、部屋を作った人のメニューから「代わりに進める」が使えます。

## 部屋を作った人だけができること

- **⏪ 1つ前の操作に戻す**：直前の操作（だれかの移動・サイコロ・スキルなど）を取り消して、その前の状態に戻します。続けて押すとさらに前へ戻れます（最大80操作）。
- テストの設定（制限時間、アイテム・スキルの有無、捕縛の判定、変装に必要なパーツ数、ターン数、ラウンド数）

## 画面の右端のアイコン

| アイコン | 内容 |
| --- | --- |
| 📜 | 公開されている予告状と、自分の予告状 |
| 🃏 | 自分のアイテムカード（怪盗）。ここから使う |
| 🔍 | スキルの効果と残りの休みターン（探偵）。ここから使う |
| 💰 | みんなの所持金・借金・探偵ラウンドの稼ぎ（順位つき） |
| 📋 | ログと記録。ファイルで保存 |
| 📖 | ルールブック（かんたんルール／くわしいルール。表や図つき） |

## 記録の保存

📋から次のファイルを保存できます。CSVはExcelやGoogleスプレッドシートでそのまま開けます。

| ボタン | ファイル | 中身 |
| --- | --- | --- |
| 行動ログ | `imukat_日時_actions.csv` | 誰が・いつ・何をしたか全部（移動元と移動先、サイコロの出目、解除の結果、スキル、捕縛、脱出など） |
| ラウンド記録 | `imukat_日時_records.csv` | 1人1ラウンド1行（結果、脱出方法、予告状、お金の内訳、移動や解除の回数など） |
| 全データ | `imukat_日時_alldata.json` | ゲームの状態まるごと |
| これまでの記録 | `imukat_history_日時.csv` | この端末で遊んだ全ゲームのラウンド記録 |

行動ログと全データには隠れた情報（全員の位置）が入っているので、部屋を作った人の画面から保存します（ゲーム終了後は全員が保存できます）。

## ルールブック

タイトル画面の「かんたんルール」「くわしいルール」、ゲーム中の右端の📖から読めます。`rules.html` を開くと別のページとして読めます（`rules.html?tab=full` でくわしいルール）。中身は `rules.js` にあり、金額やアイテム・スキルの一覧はゲームの設定（`engine.js`）から読み込むので、数値を変えるとルールブックも自動で変わります。

## 仮の内容

アイテムと探偵スキルは企画書でまだ決まっていないため、仮の効果を入れています。設定で使わないようにもできます。

## 開発メモ

- `index.html?transport=bc` で開くと、同じブラウザのタブ同士で通信します（動作確認用）。
- `node test/sim.js 300` で、ランダムに動くプレイヤーで300ゲームを自動で回して、止まらないか・情報が漏れていないかを確かめられます。
